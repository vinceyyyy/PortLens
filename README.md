# PortLens
PortLens is a lightweight open-source desktop tool for developers to inspect and manage local ports and services.
Goal is to make it easy to see which services are running, the ports they use and where conflicts occur - without any Electron bloat or the overhead of a large monitoring application.

> PortLens is currently in early development.
> There is no stable release yet.

## Planned features
- Cross platform support for Windows, macOS and Linux
- Inspect listening ports and associated processes
- Project-based port groups
- Detect port conflicts
- Kill blocking processes
- Intuitive UI and native desktop experience

## Stack
- C++ / Saucer
- SolidJS
